# ad2enum
This Repo contains the Active Directory Enumeration scripts.


### Repo Structure..
```bash
nmap
  --> nmap2enum.sh

rpc
   --> rpc2enum.sh

bloodhound
   --> bloodhound2enum.sh

git
   --> gitcheck2enum.sh
```
